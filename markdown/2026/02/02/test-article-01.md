# 测试文章 01 - Rust 语言基础

Rust 是一门系统编程语言，专注于安全、并发和性能。

## 主要特性

- **内存安全**：无需垃圾回收
- **并发性**：无数据竞争的并发
- **性能**：零成本抽象

## Hello World

```rust
fn main() {
    println!("Hello, World!");
}
```

Rust 的所有权系统是其最独特的特性，它确保内存安全而无需垃圾回收器。
