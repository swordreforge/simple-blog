# 测试文章 03 - 前端性能优化指南

前端性能优化是提升用户体验的关键因素。

## 关键指标

- **FCP** (First Contentful Paint)
- **LCP** (Largest Contentful Paint)
- **CLS** (Cumulative Layout Shift)
- **FID** (First Input Delay)

## 优化策略

1. **资源压缩**：使用 Gzip/Brotli 压缩
2. **代码分割**：按需加载
3. **图片优化**：使用 WebP 格式
4. **缓存策略**：合理设置缓存头

## 实用工具

- Lighthouse
- WebPageTest
- Chrome DevTools
