上传路由文件

上传 JSON 格式的路由文件，批量添加路由到文件路由系统

📁
点击或拖拽上传路由文件
支持 JSON 格式的单个文件或多个文件
📝 路由文件格式说明
  • 文件格式：JSON (.json)
  • 支持单个文件或批量上传
  • 每个 JSON 文件应包含路由数据
  • 支持的字段：path, body, content_type
📄 文件示例
{
  "path": "/api/example",
  "body": "{\"status\":\"ok\",\"message\":\"Hello World\"}",
  "content_type": "application/json"
}
