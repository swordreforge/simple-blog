## 🎯 嵌入式环境推荐配置

### 1. 内存管理器选择

**推荐使用 mimalloc**（内存使用效率最高）

```bash
# 编译命令
cargo build --release --features mimalloc-alloc --target x86_64-unknown-linux-musl
```

**原因：**
- 内存使用效率最高，节省 10-20% 内存
- 分配速度快，适合嵌入式 CPU
- 长期运行稳定性好
- 二进制大小影响最小

### 2. 进一步优化配置

#### 优化 Cargo.toml 以减少二进制大小

```toml
# 添加到 [profile.release]
[profile.release]
opt-level = "z"              # 已有：优化大小
lto = "fat"                  # 已有：完整 LTO
codegen-units = 1            # 已有：单代码生成单元
strip = true                 # 已有：移除符号
panic = "abort"              # 已有：减少异常处理

# 新增优化
overflow-checks = false      # 已有：禁用溢出检查
debug-assertions = false     # 已有：禁用调试断言
incremental = false          # 已有：禁用增量编译

# 进一步优化
[profile.release.package."*"]
opt-level = "s"              # 大小优化（比 "z" 更激进）
strip = true
```

#### 减少依赖和功能

```bash
# 只启用必要的功能
cargo build --release \
  --target x86_64-unknown-linux-musl \
  --features mimalloc-alloc \
  --no-default-features
```

## 🔧 嵌入式环境优化策略

### 1. 内存优化

```rust
// 在代码中使用 SmallVec 减少堆分配
use smallvec::SmallVec;

// 对于小集合，使用栈分配
fn process_small_data() -> SmallVec<[i32; 8]> {
    SmallVec::from_vec(vec![1, 2, 3])
}

// 使用字符串缓存减少分配
use once_cell::sync::Lazy;
static COMMON_STRINGS: Lazy<Vec<&str>> = Lazy::new(|| {
    vec!["default", "published", "draft"]
});
```

### 2. 启动优化

```rust
// 延迟初始化非关键组件
pub struct LazyInit<T> {
    value: OnceCell<T>,
    init_fn: fn() -> T,
}

impl<T> LazyInit<T> {
    pub fn new(init_fn: fn() -> T) -> Self {
        Self {
            value: OnceCell::new(),
            init_fn,
        }
    }

    pub fn get(&self) -> &T {
        self.value.get_or_init(self.init_fn)
    }
}
```

### 3. 数据库优化

```rust
// 在嵌入式环境中使用更小的 SQLite 配置
PRAGMA cache_size = -16000;     // 16MB 缓存（减少到 1/4）
PRAGMA mmap_size = 67108864;    // 64MB 内存映射（减少到 1/4）
PRAGMA page_size = 4096;        // 4KB 页面大小
PRAGMA temp_store = MEMORY;     // 临时表使用内存
```

### 4. 网络优化

```rust
// 减少连接池大小以节省内存
const DB_MAX_CONNECTIONS: u32 = 5;   // 从 20 减少到 5
const DB_MIN_IDLE: u32 = 1;         // 从 5 减少到 1

// 减少工作线程数
let workers = std::cmp::max(1, cpu_count / 2);  // 使用一半 CPU 核心
```

## 📦 嵌入式部署脚本

### 自动化构建脚本

```bash
#!/bin/bash
# build-embedded.sh

set -e

# 配置
TARGET="x86_64-unknown-linux-musl"
FEATURES="mimalloc-alloc"
OUTPUT_DIR="embedded-release"

# 清理
echo "🧹 清理旧的构建..."
cargo clean

# 编译
echo "🔨 编译嵌入式版本..."
cargo build --release \
  --target $TARGET \
  --features $FEATURES \
  --no-default-features

# 准备输出
echo "📦 准备输出文件..."
mkdir -p $OUTPUT_DIR
cp target/$TARGET/release/rustblog $OUTPUT_DIR/
strip $OUTPUT_DIR/rustblog

# 显示信息
echo "✅ 构建完成！"
echo "📊 二进制信息:"
ls -lh $OUTPUT_DIR/rustblog
echo ""
echo "🚀 部署命令:"
echo "   scp $OUTPUT_DIR/rustblog user@device:/usr/local/bin/"
```

## 📈 监控和调优

```bash

watch -n 5 'cat /proc/$(pgrep rustblog)/status | grep -E "VmSize|VmRSS"'

# 或使用更详细的监控
smem -P rustblog -c name pid vms rss
```

### 性能分析

