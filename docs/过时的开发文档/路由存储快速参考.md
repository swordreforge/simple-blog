## 三种存储类型对比

| 特性 | Database | Memory | File |
|------|----------|--------|------|
| 持久化 | ✅ | ❌ | ✅ |
| 性能 | 中等 | 高 | 低 |
| 可读性 | 需要工具 | 代码查看 | 文本编辑器 |
| 版本控制 | 需要导出 | 不支持 | 原生支持 |
| 适用场景 | 生产环境 | 测试/开发 | 配置管理 |
| 备份 | 需要配置 | 不支持 | 自动支持 |

## 核心概念

### RouteStorage Trait

所有存储实现都必须实现的接口：

```rust
#[async_trait::async_trait]
pub trait RouteStorage {
    async fn save_route(&self, route: &DynamicRoute) -> Result<i64, StorageError>;
    async fn load_route(&self, id: i64) -> Result<Option<DynamicRoute>, StorageError>;
    async fn load_route_by_path(&self, path: &str) -> Result<Option<DynamicRoute>, StorageError>;
    async fn delete_route(&self, id: i64) -> Result<(), StorageError>;
    async fn list_routes(&self) -> Result<Vec<DynamicRoute>, StorageError>;
    async fn count_routes(&self) -> Result<usize, StorageError>;
    async fn route_exists(&self, id: i64) -> Result<bool, StorageError>;
    async fn clear_all(&self) -> Result<(), StorageError>;
}
```

### RouteType 枚举

```rust
pub enum RouteType {
    Database,  // 数据库存储
    Memory,    // 内存存储
    File,      // 文件存储
}
```

## 快速开始

### 1. 创建路由类型管理器

```rust
use crate::app_state::create_route_type_manager;

let route_type_manager = create_route_type_manager(
    base_dir,              // 项目根目录
    dynamic_route_repo,    // 动态路由仓库
    RouteType::Database,   // 默认存储类型
)?;
```

### 2. 保存路由

```rust
use crate::db::models::{DynamicRoute, RouteType, HandlerType};
use serde_json::json;

let route = DynamicRoute {
    id: None,
    route_name: Some("我的路由".to_string()),
    route_type: RouteType::Memory,  // 指定存储类型
    path: "/my-route".to_string(),
    handler_type: HandlerType::Static,
    handler_config: json!({"content": "Hello, World!"}),
    content_source: None,
    content_template: None,
    content_type_hint: Some("text/plain".to_string()),
    enabled: true,
    priority: 0,
    created_at: chrono::Utc::now(),
    updated_at: chrono::Utc::now(),
    created_by: Some("admin".to_string()),
    metadata: None,
};

let id = route_type_manager.save_route(route).await?;
```

### 3. 加载路由

```rust
// 自动搜索所有存储类型
let route = route_type_manager.load_route(id, None).await?;

// 从指定存储类型加载
let route = route_type_manager.load_route(id, Some(RouteType::Memory)).await?;

// 根据路径加载
let route = route_type_manager.load_route_by_path("/my-route", None).await?;
```

### 4. 迁移路由

```rust
// 将路由从文件存储迁移到数据库
route_type_manager.migrate_route(id, RouteType::File, RouteType::Database).await?;

// 批量迁移所有文件存储的路由到数据库
let count = route_type_manager.migrate_all_routes(RouteType::File, RouteType::Database).await?;
println!("迁移了 {} 个路由", count);
```

### 5. 获取统计信息

```rust
let stats = route_type_manager.get_storage_stats().await?;

println!("数据库:");
println!("  总路由数: {}", stats.database.total_routes);
println!("  启用: {}", stats.database.enabled_routes);
println!("  禁用: {}", stats.database.disabled_routes);

println!("内存:");
println!("  总路由数: {}", stats.memory.total_routes);
println!("  内存使用: {} bytes", stats.memory.memory_usage_bytes);

println!("文件:");
println!("  总路由数: {}", stats.file.total_routes);
println!("  磁盘使用: {} bytes", stats.file.memory_usage_bytes);
```

## 配置示例

将 `scripts/route-storage-config-example.toml` 复制到 `data/routes/config.toml` 并修改：

```toml
[routing]
default_type = "database"  # 默认存储类型

[routing.storage.memory]
max_routes = 1000           # 最大路由数量
cleanup_interval = 3600     # 清理间隔（秒）

[routing.storage.file]
base_dir = "data/routes"    # 基础目录
backup_enabled = true       # 启用备份
backup_count = 5            # 保留 5 个备份
max_file_size = 1048576     # 最大 1MB
```

## 常见操作

### 列出所有路由

```rust
// 列出所有存储类型的路由
let all_routes = route_type_manager.list_all_routes().await?;

// 只列出内存存储的路由
let memory_routes = route_type_manager.list_routes_by_type(RouteType::Memory).await?;

// 只列出启用的路由
let enabled_routes = route_type_manager.get_all_enabled().await?;
```

### 删除路由

```rust
// 从所有存储类型中删除
route_type_manager.delete_route(id, None).await?;

// 只从内存存储中删除
route_type_manager.delete_route(id, Some(RouteType::Memory)).await?;
```

### 检查路由是否存在

```rust
let exists = route_type_manager.route_exists(id).await?;
```

### 清空存储

```rust
// 清空指定类型的存储
route_type_manager.clear_storage(RouteType::Memory).await?;

// 清空所有存储
route_type_manager.clear_all_storages().await?;
```

## 错误处理

```rust
use crate::services::route_storage::StorageError;

match route_type_manager.save_route(route).await {
    Ok(id) => println!("路由保存成功，ID: {}", id),
    Err(StorageError::CapacityExceeded(msg)) => {
        eprintln!("容量超出: {}", msg);
    }
    Err(StorageError::AlreadyExists(msg)) => {
        eprintln!("路由已存在: {}", msg);
    }
    Err(e) => {
        eprintln!("保存失败: {}", e);
    }
}
```

## 性能建议

1. **选择合适的存储类型**:
   - 生产环境: 使用 `Database`
   - 测试环境: 使用 `Memory`
   - 配置管理: 使用 `File`

2. **批量操作**:
   - 使用 `migrate_all_routes` 而不是逐个迁移
   - 使用 `list_all_routes` 一次性获取所有路由

3. **缓存策略**:
   - 内存存储本身就有缓存效果
   - 可以启用路由缓存配置

4. **清理策略**:
   - 配置适当的 `cleanup_interval`
   - 定期清理禁用的路由

## 故障排除

### 问题: 路由保存失败

**原因**: 容量超出

**解决**:
```rust
// 检查当前路由数量
let count = route_type_manager.count_all_routes().await?;
println!("当前路由数: {}", count);

// 清理旧路由或增加容量限制
```

### 问题: 文件存储权限错误

**原因**: 目录权限不足

**解决**:
```bash
chmod -R 755 data/routes
```

### 问题: 内存泄漏

**原因**: 未清理禁用的路由

**解决**:
```rust
// 启用自动清理
let storage = MemoryRouteStorage::new(1000, 3600);

// 手动清理
storage.clear_all().await?;
```
