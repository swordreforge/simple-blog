# 路由字段重构前端测试指南

## 测试环境

- **服务器地址**: http://localhost:8080
- **管理后台**: http://localhost:8080/admin/dyn-routing
- **登录凭证**: admin / admin123

## 测试目标

验证路由字段重构后的前端功能是否正常：
1. 路由列表显示正确
2. 添加路由功能正常
3. 编辑路由功能正常
4. 字段显示/隐藏逻辑正确
5. 不同 route_type 的表单验证正确

## 测试步骤

### 1. 登录测试

1. 访问 http://localhost:8080/admin/dyn-routing
2. 输入用户名: `admin`
3. 输入密码: `admin123`
4. 点击登录按钮

**预期结果**: 成功登录到动态路由管理页面

### 2. 路由列表显示测试

1. 查看路由列表
2. 验证显示的字段：
   - ID
   - 路由名称
   - 路径
   - 处理器类型
   - 状态（已启用/已禁用）
   - 优先级
   - **存储类型**（应显示为"数据库"）

**预期结果**: 
- 显示2条现有路由
- 存储类型列显示为"数据库"
- 没有"内存"或"文件"类型的路由（因为现有数据都是database类型）

### 3. 添加路由测试 - database类型

1. 点击"添加路由"按钮
2. 填写表单：
   - 路由名称: `测试路由1`
   - 路由路径: `/test-route-1`
   - 路由类型: `database` (默认选中)
   - 处理器类型: `static`
   - 优先级: `0`
3. **验证字段显示**:
   - 应该显示 `Content-Type` 字段
   - 应该显示 `内联模板` 字段
   - **不应该**显示 `模板路径` 字段
4. 填写内容：
   - Content-Type: `text/html; charset=utf-8`
   - 内联模板: `<html><body>Test Content</body></html>`
   - 处理器配置: `{}`
5. 点击"保存"按钮

**预期结果**:
- 路由创建成功
- 路由列表中显示新路由
- 存储类型显示为"数据库"

### 4. 添加路由测试 - file类型

1. 点击"添加路由"按钮
2. 填写表单：
   - 路由名称: `测试路由2`
   - 路由路径: `/test-route-2`
   - 路由类型: `file`
   - 处理器类型: `static`
   - 优先级: `0`
3. **验证字段显示**:
   - 应该显示 `Content-Type` 字段
   - **不应该**显示 `内联模板` 字段
   - 应该显示 `模板路径` 字段
4. 填写内容：
   - Content-Type: `text/html; charset=utf-8`
   - 模板路径: `templates/test.html`
   - 处理器配置: `{}`
5. 点击"保存"按钮

**预期结果**:
- 路由创建成功
- 路由列表中显示新路由
- 存储类型显示为"文件"

### 5. 添加路由测试 - memory类型

1. 点击"添加路由"按钮
2. 填写表单：
   - 路由名称: `测试路由3`

   - **不应该**显示 `模板路径` 字段
4. 填写内容：

   - 内联模板: `<html><body>Memory Content</body></html>`
   - 处理器配置: `{}`

**预期结果**:
- 路由创建成功
- 路由列表中显示新路由
- 存储类型显示为"内存"

### 6. 编辑路由测试

1. 点击任意路由的"编辑"按钮
2. **验证字段显示**:
   - 所有字段应正确填充现有数据
   - 字段显示状态应符合 route_type 的规则
3. 修改路由名称
4. 点击"保存"按钮

**预期结果**:
- 路由更新成功
- 修改后的数据正确显示

### 7. 禁用/启用路由测试

1. 点击"禁用"按钮
2. 验证状态变为"已禁用"
3. 点击"启用"按钮
4. 验证状态变为"已启用"

**预期结果**: 状态切换正常

### 8. 删除路由测试

1. 点击"删除"按钮
2. 确认删除

**预期结果**: 路由被删除

### 9. 字段验证测试

**测试1: database类型 + template_path**
1. 创建路由，选择 route_type = `database`
2. 尝试填写 template_path 字段
3. 点击"保存"

**预期结果**: 显示错误提示"database 类型路由不支持 template_path 字段"

**测试2: file类型 + inline_template**
1. 创建路由，选择 route_type = `file`
2. 尝试填写 inline_template 字段
3. 点击"保存"

**预期结果**: 显示错误提示"file 类型路由不支持 inline_template 字段"

**测试3: file类型 + 无template_path**
1. 创建路由，选择 route_type = `file`
2. 不填写 template_path 字段
3. 点击"保存"

**预期结果**: 显示错误提示"file 类型路由必须提供 template_path"

### 10. 存储统计验证

1. 查看页面顶部的统计信息
2. 验证各项数据：
   - 总路由数
   - 启用中
   - 已禁用
   - 数据库存储
   - 内存存储
   - 文件存储

**预期结果**: 统计数据与实际路由数量一致

1. 点击"删除"按钮删除测试路由
2. 或通过数据库直接删除

## 常见问题排查

### 问题1: 无法登录
- 检查用户名密码是否正确: admin / admin123
- 检查服务器是否正常运行
- 检查浏览器控制台是否有错误

### 问题2: 添加路由失败
- 检查必填字段是否都已填写
- 检查处理器配置是否为有效的JSON格式
- 检查路径是否已存在
- 检查浏览器控制台的具体错误信息

### 问题3: 字段显示不正确
- 刷新页面重试
- 检查浏览器控制台是否有JavaScript错误
- 清除浏览器缓存后重试

## 测试完成标准

✅ 所有测试步骤都能正常执行
✅ 没有JavaScript错误
✅ 字段显示/隐藏逻辑正确
✅ 表单验证正常工作
✅ 数据能正确保存和读取
✅ 统计信息准确
