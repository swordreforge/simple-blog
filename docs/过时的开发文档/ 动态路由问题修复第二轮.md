## 当前动态路由实现疑难杂症

```
{
  "type": "static",
  "content": "<!DOCTYPE html>\n<html>\n<head>\n    <meta charset=\"UTF-8\">\n    <title>自定义页面</title>\n</head>\n<body>\n    <h1>欢迎使用动态路由</h1>\n    <p>这是一个静态HTML页面示例</p>\n</body>\n</html>",
  "content_type": "text/html; charset=utf-8",
  "headers": {
    "Cache-Control": "public, max-age=3600"
  }
}
```

现在对于静态资源的处理逻辑不够完善静态内容只认json文件中的content字段，而inline_template似乎不起作用

## 修复建议

1.全方面排查json解析,建议无效化或移除对content字段的解析，或者智能截取content字段并移除content字段,将截取的内容放入inline_template中，当存入数据库的handler_config字段时,handler_config应该只关注响应体,而不处理模板内容

2.更新前端处理器配置在static状态下的json字段要求，从强制要求content变为不建议使用

3.移除模板渲染的选项因为模板渲染本质上也是静态文件

4.修复上传文件按键在上传后收不到文件，文件不更新到内联模板内容的输入框的bugq
