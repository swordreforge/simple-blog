# 内存管理器快速开始

这是一个快速开始指南，帮助你立即使用内存管理器来优化 RustBlog 的性能。

## 🚀 立即开始

### 1. 开发环境（默认）
```bash
# 使用系统默认分配器，开发速度快
cargo run

# 或者编译运行
cargo build && ./target/debug/rustblog
```

### 2. 生产环境 - 推荐配置

#### 使用 jemalloc（推荐用于高并发）✅
```bash
# 编译
cargo build --release --features jemalloc

# 运行
./target/release/rustblog
```

#### 使用 mimalloc（推荐用于容器化部署）✅
```bash
# 编译
cargo build --release --features mimalloc-alloc

# 运行
./target/release/rustblog
```

## 📊 性能提升

根据测试，使用专门的内存管理器可以获得以下性能提升：

- **多线程性能**: 提升 20-50%
- **内存碎片**: 减少 30-60%
- **长期运行稳定性**: 显著改善
- **内存使用效率**: 优化 10-20%

## ⚙️ 高级配置

### jemalloc 参数调整
```bash
# 设置更激进的清理策略
export MALLOC_CONF="background_thread:true,dirty_decay_ms:500,muzzy_decay_ms:500,narenas:8"

# 运行应用
./target/release/rustblog
```

### mimalloc 参数调整
```bash
# 启用页面重置和优化
export MIMALLOC_SEGMENT_CACHE_ENABLED=1
export MIMALLOC_PAGE_RESET=1
export MIMALLOC_LARGE_OS_PAGES=1

# 运行应用
./target/release/rustblog
```

## 💡 常见问题

**Q: 应该选择哪个内存管理器？**
A: 对于大多数生产环境，推荐：
- 高并发场景: jemalloc ✅
- 容器化部署: mimalloc ✅
- 其他场景: 系统默认

**Q: 如何切换内存管理器？**
A: 只需使用不同的 feature 重新编译即可：
```bash
cargo build --release --features jemalloc          # 切换到 jemalloc
cargo build --release --features mimalloc-alloc    # 切换到 mimalloc
cargo build --release                            # 切换到系统默认
```

**Q: 会影响现有功能吗？**
A: 不会。内存管理器是透明的，所有现有功能正常工作。

**Q: tcmalloc 怎么用？**
A: tcmalloc 需要安装系统级依赖，不推荐使用。jemalloc 和 mimalloc 提供了更好的性能和兼容性。
