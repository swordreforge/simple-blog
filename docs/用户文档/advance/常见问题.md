# 常见问题

本文档汇总了使用 RustBlog 过程中可能遇到的常见问题及其解决方案。

## 安装和部署

### Q1: 如何在 Linux 上安装 RustBlog？

**A:** RustBlog 提供预编译的二进制文件，安装步骤如下：

```bash
# 1. 下载二进制文件
wget https://github.com/swordreforge/simple-blog/releases/latest/download/rustblog-linux-x86_64

# 2. 赋予执行权限
chmod +x rustblog-linux-x86_64

# 3. 运行服务
./rustblog-linux-x86_64 --enable-cache --cache-backend auto -r
```

详细安装说明请参考：[安装指南](../basic/安装.md)

### Q2: 编译时遇到 `-Z` 选项错误怎么办？

**A:** 如果使用稳定版 Rust 编译，需要移除 `.cargo/config.toml` 中的不稳定选项：

```bash
# 编辑配置文件
nano .cargo/config.toml

# 移除所有包含 -Z 的行
```

然后重新编译：

```bash
cargo build --release
```

### Q3: 如何使用 systemd 创建持久化服务？

**A:** 创建服务文件 `/etc/systemd/system/rustblog.service`：

```ini
[Unit]
Description=RustBlog Service
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=/var/www/rustblog
ExecStart=/usr/local/bin/rustblog --enable-cache --cache-backend auto -r
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

启用并启动服务：

```bash
sudo systemctl daemon-reload
sudo systemctl enable rustblog
sudo systemctl start rustblog
```

## 配置和设置

### Q4: 如何修改管理员密码？

**A:** 方法有两种：

**方法 1：通过管理界面**
1. 登录管理员账号
2. 进入"个人中心"
3. 修改密码

**方法 2：通过数据库**
```sql
UPDATE users SET password = '新密码哈希' WHERE username = 'admin';
```

注意：密码需要使用 Argon2 哈希，建议使用管理界面修改。

### Q5: 如何备份数据？

**A:** 备份以下内容：

1. **数据库文件**
```bash
cp data/blog.db data/blog.db.backup
```

2. **上传的文件**
```bash
cp -r img img.backup
cp -r markdown markdown.backup
cp -r attachments attachments.backup
```

3. **音乐文件**
```bash
cp -r music music.backup
```

4. **配置文件**
```bash
cp .cargo/config.toml .cargo/config.toml.backup
```

### Q6: 如何恢复数据？

**A:** 恢复步骤：

1. 停止服务
```bash
sudo systemctl stop rustblog
```

2. 恢复数据库
```bash
cp data/blog.db.backup data/blog.db
```

3. 恢复文件
```bash
cp -r img.backup/* img/
cp -r markdown.backup/* markdown/
cp -r attachments.backup/* attachments/
cp -r music.backup/* music/
```

4. 启动服务
```bash
sudo systemctl start rustblog
```

## 外观和模板

### Q7: 背景图片不显示怎么办？

**A:** 检查以下几点：

1. **图片路径是否正确**
   - 检查图片文件是否存在于 `img/` 目录
   - 确认路径格式正确（如 `/img/bg.webp`）

2. **图片格式是否支持**
   - 支持格式：jpg, png, webp, gif
   - 确认文件扩展名正确

3. **文件权限是否正确**
```bash
chmod 644 img/*.webp
chmod 755 img
```

4. **浏览器缓存**
   - 清除浏览器缓存
   - 使用隐私模式测试

### Q8: 如何自定义 CSS 样式？

**A:** 可以通过以下方式自定义：

1. **使用自定义 CSS 字段**
   - 管理员设置 → 外观 → 自定义 CSS
   - 输入 CSS 代码

2. **修改模板文件**
   - 编辑 `templates/css/` 下的 CSS 文件
   - 需要重启服务生效

3. **使用 Live2D 或音乐播放器的自定义 CSS**
   - 管理员设置 → 音乐 → 自定义 CSS
   - 管理员设置 → 模板 → Live2D 设置

### Q9: 暗色模式启用后颜色不协调？

**A:** 解决方法：

1. **重新调整毛玻璃颜色**
   - 使用深色系的颜色配置
   - 降低透明度

2. **关闭暗色模式，手动配置**
   - 关闭暗色模式
   - 手动配置深色主题

3. **推荐的深色配色方案**
```
导航栏毛玻璃颜色: rgba(30, 30, 30, 0.8)
导航栏文字颜色: #e5e5e5
卡片毛玻璃颜色: rgba(50, 50, 50, 0.4)
底栏毛玻璃颜色: rgba(40, 40, 40, 0.5)
```

## 音乐功能

### Q10: 音乐无法播放怎么办？

**A:** 检查以下几点：

1. **音乐文件格式**
   - 确认文件格式支持（mp3, flac, ogg, wav）
   - 尝试使用 MP3 格式

2. **浏览器兼容性**
   - 确认浏览器支持该音频格式
   - 尝试使用 Chrome 或 Firefox

3. **文件路径**
   - 确认音乐文件已正确上传到 `music/` 目录
   - 检查文件权限

4. **音乐设置**
   - 确认音乐播放器已启用
   - 检查音量设置

### Q11: 音乐元数据提取失败？

**A:** 可能原因和解决方法：

1. **缺少元数据标签**
   - 使用元数据编辑工具添加 ID3 或 FLAC 标签
   - 推荐工具：Mp3tag, MusicBrainz Picard

2. **标签格式不标准**
   - 使用标准工具重新添加标签
   - 确保标签格式正确

3. **手动编辑信息**
   - 在音乐管理页面手动编辑标题和艺术家

### Q12: 自动播放不工作？

**A:** 浏览器通常会阻止自动播放，原因：

1. **浏览器策略**
   - 现代浏览器阻止未经用户交互的自动播放

2. **解决方法**
   - 让用户手动点击播放
   - 或在用户首次交互后启动音乐

## 动态路由

### Q13: 动态路由不生效怎么办？

**A:** 检查以下几点：

1. **路由是否已启用**
   - 确认路由的 `enabled` 字段为 `true`

2. **路径是否正确**
   - 确认路径格式正确
   - 检查是否有多余的斜杠

3. **优先级冲突**
   - 检查路由优先级
   - 确认没有更高优先级的路由匹配

4. **查看日志**
```bash
journalctl -u rustblog -f
```

### Q14: 如何测试动态路由？

**A:** 使用"测试路由"功能：

1. 进入"管理员设置 → 动态路由"
2. 点击"测试路由"按钮
3. 输入路由配置
4. 查看测试结果

或使用 `curl` 命令：

```bash
curl -I http://localhost:8080/your-route-path
```

### Q15: 动态路由会影响性能吗？

**A:** 动态路由性能接近静态路由：

- 16 分片优化，减少锁竞争
- Radix Tree 高效匹配
- 热更新影响 < 5%

性能对比：

| 场景 | QPS | 延迟(P99) |
|-----|-----|----------|
| 静态路由 | 85,000 | 2ms |
| 动态路由（16分片） | 78,000 | 2.5ms |

## 快捷键

### Q16: 快捷键不生效怎么办？

**A:** 检查以下几点：

1. **焦点是否在输入框中**
   - 输入框中快捷键会被禁用
   - 点击页面其他区域激活快捷键

2. **特殊模式**
   - 检查是否在专注模式或查看器中
   - 部分快捷键会被禁用或修改

3. **浏览器拦截**
   - 检查浏览器扩展是否拦截了快捷键
   - 尝试禁用扩展后测试

4. **刷新页面**
   - 有时需要刷新页面重新加载快捷键

### Q17: 如何禁用快捷键？

**A:** 当前版本暂不支持全局禁用快捷键。

临时禁用的方法：
- 将焦点保持在输入框中
- 或使用鼠标操作

## Live2D

### Q18: Live2D 不显示怎么办？

**A:** 检查以下几点：

1. **网络连接**
   - Live2D 需要从 CDN 加载资源
   - 确认网络连接正常

2. **浏览器支持**
   - 确认浏览器支持 WebGL
   - 尝试使用 Chrome 或 Firefox

3. **模型配置**
   - 确认模型 ID 正确
   - 检查 CDN 路径

4. **刷新页面**
   - 有时需要刷新页面重新加载资源

### Q19: 如何自定义 Live2D 模型？

**A:** 方法：

1. **使用自定义模型路径**
   - 管理员设置 → 模板 → Live2D 设置
   - 填写自定义模型路径

2. **模型文件要求**
   - 需要遵循 Live2D Widget 规范
   - 包含必要的 JSON 和资源文件

3. **或修改 CDN 路径**
   - 使用其他 CDN 源
   - 或托管到自己的服务器

## 附件功能

### Q20: 附件上传失败？

**A:** 检查以下几点：

1. **文件大小**
   - 确认文件大小未超过限制
   - 默认限制：500MB

2. **文件类型**
   - 确认文件类型在允许列表中
   - 检查文件扩展名是否正确

3. **磁盘空间**
   - 确认服务器磁盘空间充足
   - 检查目录权限

4. **网络连接**
   - 确认网络连接稳定
   - 尝试使用较小的文件测试

### Q21: 如何修改附件上传限制？

**A:** 方法：

1. **通过管理界面**
   - 管理员设置 → 模板
   - 修改"附件最大文件大小"

2. **通过数据库**
```sql
UPDATE settings SET value = '新大小（字节）' WHERE key = 'attachment_max_size';
```

3. **修改允许的文件类型**
```sql
UPDATE settings SET value = 'jpg,png,webp' WHERE key = 'attachment_allowed_types';
```

## 性能优化

### Q22: 如何降低内存占用？

**A:** 方法：

1. **使用默认配置**
   - RustBlog 已经过优化
   - 默认配置已经是最佳方案

2. **禁用不必要的功能**
   - 关闭 Live2D
   - 关闭音乐播放器
   - 关闭飘字效果

3. **优化数据库**
   - 定期清理旧数据
   - 使用 VACUUM 命令优化

4. **启用缓存**
```bash
./rustblog --enable-cache --cache-backend auto
```

### Q23: 如何提高响应速度？

**A:** 方法：

1. **启用缓存**
   - 使用 `--enable-cache` 参数
   - 选择合适的缓存后端

2. **优化图片**
   - 使用 WebP 格式
   - 压缩图片大小

3. **使用 CDN**
   - 将静态资源托管到 CDN
   - 减少服务器负载

4. **升级硬件**
   - 增加内存
   - 使用更快的 CPU

## 安全问题

### Q24: 如何加强安全性？

**A:** 建议措施：

1. **使用 HTTPS**
   - 配置 SSL 证书
   - 强制 HTTPS 访问

2. **修改默认端口**
   - 不使用默认的 8080 端口
   - 使用反向代理（如 Nginx）

3. **定期更新**
   - 及时更新 RustBlog
   - 定期检查安全公告

4. **备份**
   - 定期备份数据
   - 测试恢复流程

### Q25: 如何设置防火墙规则？

**A:** 示例（使用 ufw）：

```bash
# 允许 SSH
ufw allow 22/tcp

# 允许 HTTP
ufw allow 80/tcp

# 允许 HTTPS
ufw allow 443/tcp

# 启用防火墙
ufw enable

# 查看状态
ufw status
```

## 其他问题

### Q26: 如何查看日志？

**A:** 方法：

1. **使用 journalctl（systemd）**
```bash
journalctl -u rustblog -f
```

2. **查看日志文件**
```bash
tail -f data/logs/rustblog.log
```

3. **查看实时日志**
```bash
./rustblog --enable-cache --cache-backend auto -r
```

### Q27: 如何重置所有设置？

**A:** 警告：此操作不可逆！

1. **备份数据**
```bash
cp data/blog.db data/blog.db.backup
```

2. **删除数据库**
```bash
rm data/blog.db
```

3. **重启服务**
```bash
sudo systemctl restart rustblog
```

4. **重新初始化**
   - 系统会自动创建新的数据库
   - 需要重新配置所有设置

### Q28: 如何升级到最新版本？

**A:** 步骤：

1. **备份数据**
```bash
# 备份数据库
cp data/blog.db data/blog.db.backup

# y备份文件
cp -r img img.backup
cp -r markdown markdown.backup
cp -r attachments attachments.backup
cp -r music music.backup
```

2. **下载新版本**

访问：``https://github.com/swordreforge/simple-blog/releases``

3. **停止服务**
```bash
sudo systemctl stop rustblog
```

4. **替换二进制文件**
```bash
cp rustblog-linux-x86_64 /usr/local/bin/rustblog
chmod +x /usr/local/bin/rustblog
```

5. **启动服务**
```bash
sudo systemctl start rustblog
```

6. **验证升级**
```bash
./rustblog --version
```
