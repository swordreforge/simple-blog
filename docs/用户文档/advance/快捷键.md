# 快捷键

RustBlog 提供了完整的快捷键系统，让您可以通过键盘快速访问各种功能，提高使用效率。

## 快捷键分类

快捷键分为两类：
1. **全局快捷键** - 在所有页面都可用
2. **页面快捷键** - 仅在特定页面可用

## 全局快捷键

### 导航快捷键

| 按键 | 功能 | 说明 |
|------|------|------|
| `1` | 跳转主页 | 返回网站首页 |
| `2` | 跳转文章页 | 查看最新文章列表 |
| `3` | 跳转归档页 | 查看文章归档 |
| `4` | 跳转关于页 | 查看关于页面 |
| `5` | 打开个人中心 | 显示个人中心模态框 |
| `6` | 跳转编辑器 | 打开 Markdown 编辑器 |
| `f` | 跳转友链 | 查看友情链接 |
| `a` | 跳转管理页 | 跳转到管理员设置（需管理员权限） |
| `l` | 打开登录框 | 显示登录模态框 |

### 系统快捷键

| 按键 | 功能 | 说明 |
|------|------|------|
| `/` | 显示快捷键帮助 | 弹出快捷键帮助对话框 |
| `Escape` | 关闭所有模态框 | 关闭当前打开的所有模态框 |

### 音乐控制快捷键

| 按键 | 功能 | 说明 |
|------|------|------|
| `空格` | 播放/暂停 | 切换音乐播放状态 |
| `→` (右箭头) | 下一首 | 播放下一首音乐 |
| `←` (左箭头) | 上一首 | 播放上一首音乐 |
| `↑` (上箭头) | 音量+ | 增加音量 |
| `↓` (下箭头) | 音量- | 降低音量 |
| `m` | 静音 | 切换静音状态 |
| `p` | 播放列表 | 显示/隐藏播放列表 |

## 文章页快捷键

在文章详情页面，可以使用以下快捷键：

| 按键 | 功能 | 说明 |
|------|------|------|
| `s` | 切换侧边栏 | 显示/隐藏文章侧边栏 |
| `t` | 切换阅读模式 | 切换舒适阅读模式 |
| `h` | 切换顶栏和底栏 | 隐藏/显示顶部导航和底部信息 |
| `f` | 全屏模式 | 进入/退出全屏阅读 |
| `Escape` | 退出全屏 | 退出全屏模式 |

### 专注模式快捷键

在归档页、关于页等页面，还支持专注模式快捷键：

| 按键 | 功能 | 说明 |
|------|------|------|
| `↑` / `↓` | 导航焦点 | 在专注模式下上下导航 |
| `←` / `→` | 切换视图 | 在专注模式下左右切换 |

## 快捷键提示

RustBlog 会在页面上显示快捷键提示：

1. **按钮提示** - 悬停在按钮上会显示对应的快捷键
2. **帮助对话框** - 按 `/` 键可查看完整的快捷键列表
3. **智能提示** - 根据当前页面动态显示可用的快捷键

## 使用技巧

### 快速导航

使用数字键 `1-6` 可以快速跳转到主要页面，无需使用鼠标点击导航菜单。

### 音乐控制

使用方向键控制音乐播放，无需切换到音乐播放器，可以在阅读文章的同时控制音乐。

### 阅读模式

在文章页使用 `t` 键快速切换到阅读模式，使用 `h` 键隐藏导航栏，享受沉浸式阅读体验。

### 专注模式

在归档页使用方向键快速浏览文章列表，提高阅读效率。

## 快捷键冲突处理

### 输入框优先级

当焦点在输入框、文本区域或可编辑元素上时，快捷键会被禁用，确保正常的文本输入。

### 特殊场景处理

以下场景下，部分快捷键会被禁用或修改：

1. **播放列表打开时** - 上下箭头用于选择音乐，不影响快捷键
2. **专注模式** - 方向键用于导航，不触发音乐控制
3. **图片/代码查看器** - 快捷键优先用于查看器操作

## 快捷键帮助

查看完整快捷键列表：

1. 按下 `/` 键
2. 查看弹出的帮助对话框
3. 帮助对话框按 `Escape` 键关闭

## 自定义快捷键

当前版本暂不支持自定义快捷键，所有快捷键均为预设值。未来版本可能会添加自定义功能。

## 常见问题

**Q: 快捷键不生效怎么办？**

A: 请检查：
1. 焦点是否在输入框中（输入框中快捷键会被禁用）
2. 是否在特殊模式下（如专注模式、查看器）
3. 浏览器是否拦截了快捷键
4. 尝试刷新页面

**Q: 如何禁用快捷键？**

A: 当前版本暂不支持禁用快捷键，如需避免快捷键触发，请将焦点保持在输入框中。

**Q: 快捷键与其他网站冲突怎么办？**

A: RustBlog 的快捷键仅在页面激活时生效，不会影响其他标签页。如果与其他扩展冲突，请检查浏览器扩展设置。

**Q: 移动端如何使用快捷键？**

A: 移动端不支持键盘快捷键，请使用触摸操作。

## 最佳实践

1. **记住常用快捷键** - `1-6` 数字键是最常用的导航快捷键
2. **善用帮助** - 忘记快捷键时按 `/` 查看帮助
3. **专注阅读** - 使用 `t` 和 `h` 快捷键进入沉浸式阅读
4. **音乐伴读** - 使用方向键控制音乐，无需打断阅读
