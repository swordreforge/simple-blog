# 模板设置

RustBlog 的模板设置允许您自定义博客的各种文本内容、显示选项和功能模块。所有模板设置都可以在**管理员设置 → 模板**页面进行配置。

## 访问模板设置

1. 登录管理员账号
2. 点击侧边栏的"管理员设置"
3. 选择"模板"标签页

## 基础信息设置

### 主页标题

- **个人主页标题** (`template_name`)
  - 类型：字符串
  - 默认值：`欢迎来到我的博客`
  - 说明：显示在浏览器标签页和首页的标题
  - 建议：使用简洁、有吸引力的标题

### 欢迎语

- **首页欢迎语** (`template_greting`)
  - 类型：字符串
  - 默认值：`这是一个使用 Rust 语言构建的个人博客系统，支持文章管理、数据分析等功能。`
  - 说明：显示在首页顶部的欢迎文字
  - 支持：纯文本，建议 1-2 句话
  - 示例：
    - `欢迎来到我的个人博客，这里记录了我的学习和成长历程。`
    - `分享技术，交流心得，共同进步。`

### 版权信息

- **版权年份** (`template_year`)
  - 类型：字符串
  - 默认值：`2026`
  - 说明：页脚显示的版权年份
  - 格式：支持单年份或年份范围
  - 示例：
    - `2026`（单年份）
    - `2020-2026`（年份范围）

- **页脚信息** (`template_foods`)
  - 类型：字符串
  - 默认值：`我的博客`
  - 说明：显示在页面底部的版权文字
  - 示例：
    - `© 2026 MyBlog. All rights reserved.`
    - `Made with ❤️ by YourName`

## 文章显示设置

### 文章标题

- **是否显示文章标题** (`template_article_title`)
  - 类型：布尔值
  - 默认值：`true`
  - 说明：在文章页面是否显示文章标题

- **文章标题前缀** (`template_article_title_prefix`)
  - 类型：字符串
  - 默认值：`文章`
  - 说明：在文章标题前显示的前缀文字
  - 示例：
    - `文章`（默认）
    - `Post`（英文）
    - 留空（不显示前缀）

### 文章摘要

- **是否启用文章摘要功能** (`passage_summarize_enabled`)
  - 类型：布尔值
  - 默认值：`true`
  - 说明：自动生成文章摘要并显示
  - 技术实现：基于 TextRank 算法的中文摘要

## 界面交互设置

### 切换提示

- **是否显示切换界面提示** (`template_switch_notice`)
  - 类型：布尔值
  - 默认值：`true`
  - 说明：用户切换标签页时显示提示

- **切换标签页时显示的提示文字** (`template_switch_notice_text`)
  - 类型：字符串
  - 默认值：`回来继续阅读`
  - 说明：标签页切换时显示的文字
  - 示例：
    - `别忘了回来继续阅读哦~`
    - `期待您的再次光临`

### 外部链接安全

- **是否启用外部链接跳转警告** (`external_link_warning`)
  - 类型：布尔值
  - 默认值：`true`
  - 说明：点击外部链接时弹出确认提示
  - 作用：防止用户误跳转到恶意网站

- **外部链接白名单** (`external_link_whitelist`)
  - 类型：字符串
  - 默认值：`github.com,gitee.com,stackoverflow.com`
  - 说明：白名单内的域名不需要警告
  - 格式：逗号分隔的域名列表
  - 示例：
    - `github.com,gitee.com,stackoverflow.com,cnblogs.com`
    - `*.example.com`（通配符匹配）

- **外部链接警告提示文字** (`external_link_warning_text`)
  - 类型：字符串
  - 默认值：`您即将离开本站，前往外部链接`
  - 说明：警告提示框中显示的文字

## Live2D 看板娘设置

Live2D 是一种 2D 动画技术，可以在网页上显示一个可爱的动画角色。

### 基础设置

- **是否启用 Live2D 看板娘** (`live2d_enabled`)
  - 类型：布尔值
  - 默认值：`false`
  - 说明：启用后在页面上显示 Live2D 角色
  - 注意：首次启用可能需要加载外部资源

### 显示页面控制

您可以控制 Live2D 在不同页面的显示：

- **是否在首页显示 Live2D** (`live2d_show_on_index`)
  - 类型：布尔值
  - 默认值：`true`

- **是否在文章页显示 Live2D** (`live2d_show_on_passage`)
  - 类型：布尔值
  - 默认值：`true`

- **是否在归档页显示 Live2D** (`live2d_show_on_collect`)
  - 类型：布尔值
  - 默认值：`true`

- **是否在关于页显示 Live2D** (`live2d_show_on_about`)
  - 类型：布尔值
  - 默认值：`true`

- **是否在管理页显示 Live2D** (`live2d_show_on_admin`)
  - 类型：布尔值
  - 默认值：`false`

### 模型配置

- **Live2D 模型 ID** (`live2d_model_id`)
  - 类型：字符串
  - 默认值：`1`
  - 说明：选择不同的 Live2D 模型
  - 可选值：
    - `1` - shizuku
    - `2` - koharu
    - `3` - haruto
    - `4` - izumi

- **Live2D 自定义模型路径** (`live2d_model_path`)
  - 类型：字符串
  - 默认值：`(空)`
  - 说明：使用自定义的 Live2D 模型
  - 格式：相对路径或 URL
  - 示例：
    - `/live2d/my-model/`
    - `https://example.com/live2d/models/`

- **Live2D CDN 路径** (`live2d_cdn_path`)
  - 类型：字符串
  - 默认值：`https://unpkg.com/live2d-widget-model@1.0.5/`
  - 说明：从 CDN 加载 Live2D 资源
  - 注意：自定义模型路径优先级高于 CDN

### 显示样式

- **Live2D 显示位置** (`live2d_position`)
  - 类型：字符串
  - 默认值：`right`
  - 可选值：`left`（左侧）、`right`（右侧）

- **Live2D 宽度** (`live2d_width`)
  - 类型：字符串（CSS 值）
  - 默认值：`280px`
  - 说明：Live2D 角色的显示宽度

- **Live2D 高度** (`live2d_height`)
  - 类型：字符串（CSS 值）
  - 默认值：`250px`
  - 说明：Live2D 角色的显示高度

## 赞助功能设置

为您的博客添加赞助功能，让读者可以支持您的内容创作。

- **是否启用赞助功能** (`sponsor_enabled`)
  - 类型：布尔值
  - 默认值：`false`
  - 说明：在页面底部显示赞助按钮

- **赞助模态框标题** (`sponsor_title`)
  - 类型：字符串
  - 默认值：`感谢您的支持`

- **赞助图片路径** (`sponsor_image`)
  - 类型：字符串
  - 默认值：`/img/avatar.webp`
  - 说明：赞助页面显示的图片
  - 建议使用收款二维码图片

- **赞助描述文字** (`sponsor_description`)
  - 类型：字符串
  - 默认值：`如果您觉得这个博客对您有帮助，欢迎赞助支持！`

- **赞助按钮文字** (`sponsor_button_text`)
  - 类型：字符串
  - 默认值：`❤️ 赞助支持`

## 全局头像设置

- **全局头像路径** (`global_avatar`)
  - 类型：字符串
  - 默认值：`/img/avatar.webp`
  - 说明：用于评论、个人中心等位置的头像
  - 支持格式：jpg, png, webp, gif
  - 建议尺寸：200x200 像素

## 附件设置

- **附件默认可见性** (`attachment_default_visibility`)
  - 类型：字符串
  - 默认值：`public`
  - 可选值：
    - `public` - 公开可见
    - `private` - 仅管理员可见

- **附件最大文件大小** (`attachment_max_size`)
  - 类型：数字
  - 默认值：`524288000`（500MB）
  - 单位：字节
  - 常见值：
    - `104857600` = 100MB
    - `524288000` = 500MB
    - `1073741824` = 1GB

- **附件允许的文件类型** (`attachment_allowed_types`)
  - 类型：字符串
  - 默认值：`jpg,jpeg,png,gif,mp4,mp3,pdf,doc,docx,xls,xlsx,ppt,pptx,zip,rar,7z,tar,gz`
  - 说明：允许上传的文件扩展名
  - 格式：逗号分隔的扩展名列表
  - 示例：
    - `jpg,png,gif`（仅图片）
    - `mp4,webm,mov`（仅视频）
    - `pdf,doc,docx`（仅文档）

## 保存设置

完成模板配置后，点击页面底部的"保存"按钮即可应用更改。部分设置可能需要刷新页面才能完全生效。

## 常见问题

**Q: Live2D 不显示怎么办？**

A: 请检查：
1. 网络连接是否正常（需要加载 CDN 资源）
2. 浏览器是否支持 WebGL
3. 模型 ID 是否正确
4. 尝试刷新页面

**Q: 如何自定义 Live2D 模型？**

A: 您可以：
1. 在 `live2d_model_path` 中填写自定义模型路径
2. 或在 `live2d_cdn_path` 中修改 CDN 地址
3. 模型文件需要遵循 Live2D Widget 的规范

**Q: 附件上传失败？**

A: 请检查：
1. 文件大小是否超过限制
2. 文件类型是否在允许列表中
3. 磁盘空间是否充足
4. 目录权限是否正确

**Q: 外部链接白名单不生效？**

A: 请确保：
1. 域名格式正确（如 `github.com`，不需要 `https://`）
2. 多个域名用逗号分隔，不要有空格
3. 域名拼写正确
