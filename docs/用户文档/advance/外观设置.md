# 外观设置

RustBlog 提供了丰富的外观自定义选项，让您可以轻松打造独特的博客风格。所有外观设置都可以在**管理员设置 → 外观**页面进行配置。

## 访问外观设置

1. 登录管理员账号
2. 点击侧边栏的"管理员设置"
3. 选择"外观"标签页

## 背景设置

### 背景图片

RustBlog 支持桌面端和移动端使用不同的背景图片，提供最佳的视觉体验。

**设置项**：

- **页面背景图片路径** (`background_image`)
  - 类型：字符串
  - 默认值：`/img/test.webp`
  - 说明：桌面端显示的背景图片路径
  - 支持格式：jpg, png, webp, gif

- **移动端背景图片** (`mobile_background_image`)
  - 类型：字符串
  - 默认值：`/img/mobile-test.webp`
  - 说明：移动端设备显示的背景图片路径
  - 建议使用较小尺寸的图片以优化加载速度

**使用建议**：
- 桌面端建议使用 1920x1080 或更高分辨率的图片
- 移动端建议使用 750x1334 或类似比例的图片
- 使用 WebP 格式可以获得更好的压缩效果

### 背景样式

- **背景图片尺寸** (`background_size`)
  - 类型：枚举
  - 可选值：
    - `cover`：覆盖整个容器（推荐）
    - `contain`：完整显示图片
    - `auto`：原始尺寸
  - 默认值：`cover`

- **背景图片位置** (`background_position`)
  - 类型：字符串
  - 常见值：`center`, `top`, `bottom`, `left`, `right`
  - 默认值：`center`

- **背景图片重复方式** (`background_repeat`)
  - 类型：枚举
  - 可选值：`no-repeat`, `repeat`, `repeat-x`, `repeat-y`
  - 默认值：`no-repeat`

- **背景图片滚动方式** (`background_attachment`)
  - 类型：枚举
  - 可选值：
    - `fixed`：固定背景（视差效果）
    - `scroll`：随页面滚动
  - 默认值：`fixed`

### 视觉效果

- **背景模糊程度** (`blur_amount`)
  - 类型：字符串（CSS 值）
  - 默认值：`20px`
  - 说明：对背景图片应用模糊效果
  - 范围：0px - 100px

- **背景饱和度** (`saturate_amount`)
  - 类型：字符串（CSS 百分比）
  - 默认值：`180%`
  - 说明：调整背景图片的色彩饱和度
  - 范围：0% - 300%
  - 0% 为黑白，100% 为原始颜色，>100% 为增强色彩

- **全局透明度** (`global_opacity`)
  - 类型：数字
  - 默认值：`0.15`
  - 说明：控制整体界面的透明度
  - 范围：0 - 1
  - 数值越小，背景越明显

## 毛玻璃效果

RustBlog 使用毛玻璃效果为导航栏、卡片和底栏提供现代化的视觉效果。

### 导航栏设置

- **导航栏毛玻璃颜色** (`navbar_glass_color`)
  - 类型：字符串（RGBA 格式）
  - 默认值：`rgba(60, 60, 60, 0.6)`
  - 格式：`rgba(R, G, B, A)`
    - R、G、B：0-255 的颜色值
    - A：0-1 的透明度值
  - 示例：`rgba(255, 255, 255, 0.8)`（白色半透明）

- **导航栏文字颜色** (`navbar_text_color`)
  - 类型：字符串（颜色值）
  - 默认值：`#ffffff`
  - 格式支持：十六进制、RGB、颜色名称
  - 示例：
    - `#ffffff`（白色）
    - `rgb(255, 255, 255)`
    - `white`

### 卡片设置

- **页面卡片毛玻璃颜色** (`card_glass_color`)
  - 类型：字符串（RGBA 格式）
  - 默认值：`rgba(220, 138, 221, 0.2)`
  - 说明：文章卡片、侧边栏等元素的背景色
  - 建议使用低透明度以保持背景可见

### 底栏设置

- **底栏毛玻璃颜色** (`footer_glass_color`)
  - 类型：字符串（RGBA 格式）
  - 默认值：`rgba(220, 138, 221, 0.25)`
  - 说明：页面底部版权信息栏的背景色

## 飘字效果

飘字效果是一个有趣的交互功能，会在页面上显示漂浮的文字。

- **是否启用飘字效果** (`floating_text_enabled`)
  - 类型：布尔值
  - 默认值：`false`
  - 说明：启用后会在页面上显示漂浮的文字

- **飘字效果文本列表** (`floating_texts`)
  - 类型：JSON 数组
  - 默认值：`["perfect", "good", "excellent", "extraordinary", "legend"]`
  - 说明：自定义飘字内容
  - 格式：`["文本1", "文本2", "文本3"]`
  - 示例：
    ```json
    ["你好", "欢迎", "RustBlog", "不错", "很棒"]
    ```

## 暗色模式

- **是否启用暗色模式** (`dark_mode_enabled`)
  - 类型：布尔值
  - 默认值：`false`
  - 说明：切换到暗色主题，适合夜间阅读
  - 注意：此功能会覆盖部分自定义颜色设置

## 保存设置

完成外观配置后，点击页面底部的"保存"按钮即可应用更改。部分设置可能需要刷新页面才能完全生效。

## 常见问题

**Q: 背景图片不显示怎么办？**

A: 请检查以下几点：
1. 图片路径是否正确
2. 图片文件是否存在于 `img/` 目录
3. 图片格式是否支持（jpg, png, webp, gif）

**Q: 如何恢复默认外观？**

A: 点击"恢复默认"按钮，所有外观设置将重置为初始值。

**Q: 毛玻璃效果不明显？**

A: 尝试调整以下参数：
1. 降低背景模糊程度
2. 增加 RGBA 颜色的透明度（A 值）
3. 降低全局透明度

**Q: 暗色模式启用后颜色不协调？**

A: 暗色模式会覆盖部分颜色设置，建议：
1. 在暗色模式下重新调整毛玻璃颜色
2. 使用深色系的颜色配置
3. 或者关闭暗色模式，手动配置深色主题
