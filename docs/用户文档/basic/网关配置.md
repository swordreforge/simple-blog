# 网关配置指南

本文档介绍如何使用反向代理网关（Nginx、H2O、OpenResty）来部署 RustBlog，提升性能、安全性和可维护性。

## 为什么需要网关？

使用反向代理网关作为前端服务器有以下优势：

### 1. 性能优化
- **静态资源缓存**：网关可以缓存 JS、CSS、图片等静态资源，减轻后端压力
- **Gzip/Brotli 压缩**：在传输前压缩内容，减少带宽使用
- **连接复用**：与后端保持持久连接，减少 TCP 握手开销
- **HTTP/2 和 HTTP/3 支持**：提升页面加载速度
- **零拷贝传输**：减少数据在内核空间的复制，提高吞吐量

### 2. 安全加固
- **SSL/TLS 终止**：统一管理 HTTPS 证书，简化后端配置
- **安全响应头**：自动添加 HSTS、CSP、X-Frame-Options 等安全头
- **DDoS 防护**：限制请求速率，防止恶意攻击
- **WAF 功能**：拦截恶意请求（如 SQL 注入、XSS 等）
- **隐藏后端信息**：客户端无法直接访问后端服务器

### 3. 负载均衡
- **多实例分发**：将请求分发到多个后端实例，提高可用性
- **健康检查**：自动检测后端服务状态，故障时自动剔除
- **会话保持**：保持用户会话的一致性

### 4. 灵活部署
- **端口映射**：通过不同域名或路径路由到不同服务
- **灰度发布**：支持 A/B 测试和渐进式发布
- **易于扩展**：无需修改后端代码即可添加新功能

## Nginx 配置

### 安装 Nginx

```bash
# Ubuntu/Debian
apt update
apt install nginx -y

# CentOS/RHEL
yum install nginx -y
```

### 基础配置示例

```nginx
# /etc/nginx/conf.d/rustblog.conf

# HTTP 强制跳转 HTTPS
server {
    listen 80;
    server_name your-domain.com;
    return 301 https://$server_name$request_uri;
}

# HTTPS 主配置
server {
    listen 443 ssl http2;
    server_name your-domain.com;

    # SSL 证书配置
    ssl_certificate /etc/letsencrypt/live/your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;

    # SSL 优化配置
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers 'ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-RSA-AES256-GCM-SHA384';
    ssl_prefer_server_ciphers off;
    ssl_session_timeout 1d;
    ssl_session_cache shared:SSL:10m;

    # 安全响应头
    add_header Strict-Transport-Security "max-age=63072000; includeSubDomains; preload" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header Referrer-Policy "strict-origin-when-cross-origin" always;
    add_header Content-Security-Policy "default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'" always;

    # Gzip 压缩
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml application/xml+rss text/javascript;

    # 反向代理配置
    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Connection "";

        # 超时配置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    # 静态资源缓存配置
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
```

### 高级配置（负载均衡）

```nginx
upstream rustblog_backend {
    least_conn;
    server 127.0.0.1:8080 weight=1;
    server 127.0.0.1:8081 weight=1;
    server 127.0.0.1:8082 weight=1;
    keepalive 32;
}

server {
    listen 443 ssl http2;
    server_name your-domain.com;

    location / {
        proxy_pass http://rustblog_backend;
        proxy_http_version 1.1;
        proxy_set_header Connection "";
    }
}
```

```bash

# 重载配置

# 启动服务

```

## H2O 配置

H2O 是一个高性能的 HTTP 服务器，特别适合现代 Web 应用。它对 HTTP/2 和 HTTP/3 的支持非常出色，性能优异。

### 从源码编译安装

```bash
# 安装依赖
apt update
apt install -y build-essential cmake libssl-dev zlib1g-dev libyaml-dev libuv1-dev ragel libc-dev git

# 克隆源码
git clone https://github.com/h2o/h2o.git
cd h2o

# 创建构建目录
mkdir build && cd build

# CMake 配置
cmake \
  -DCMAKE_INSTALL_PREFIX=/usr/local \
  -DCMAKE_BUILD_TYPE=Release \
  -DWITH_MRUBY=ON \
  -DWITH_QUIC=ON \
  -DWITH_URING=ON \
  -DWITH_KTLS=ON \
  -DWITH_JEMALLOC=ON \
  -DWITH_LIBUV=ON \
  ..

# 编译安装
make -j$(nproc)
make install
```

### 系统优化

```bash
# 开启 BBR 拥塞控制
echo "net.core.default_qdisc=fq" >> /etc/sysctl.conf
echo "net.ipv4.tcp_congestion_control=bbr" >> /etc/sysctl.conf
sysctl -p

# 提升文件句柄限制
ulimit -n 65535
echo "* soft nofile 65535" >> /etc/security/limits.conf
echo "* hard nofile 65535" >> /etc/security/limits.conf

# 防火墙放行端口
ufw allow 80/tcp
ufw allow 443/tcp
ufw allow 443/udp
ufw reload
```

### 生产级配置示例

```yaml
# /etc/h2o/h2o.conf

# 全局性能配置
num-threads: 2
max-connections: 1024
tcp-reuseport: ON
tcp-fastopen: 4096

# 零拷贝优化（大文件传输关键）
proxy.zerocopy: ON

# HTTP/2 优化
http2-casper: ON
http2-reprioritize-blocking-assets: ON
http2-idle-timeout: 30
http2-max-streams: 100
http2-max-concurrent-requests-per-connection: 50

# HTTP/3 优化
http3-idle-timeout: 30
http3-gso: ON

# 日志配置
access-log: /var/log/h2o/access.log
error-log: /var/log/h2o/error.log

# 压缩配置
compress: ON
compress-minimum-size: 512

hosts:
  # HTTP 强制跳转 HTTPS
  "your-domain.com:80":
    listen:
      port: 80
      host: 0.0.0.0
    paths:
      "/":
        redirect:
          status: 301
          url: https://your-domain.com

  # HTTPS 主配置
  "your-domain.com:443":
    # TCP 监听器（HTTP/1.1 和 HTTP/2）
    listen: &listen_ssl
      port: 443
      host: 0.0.0.0
      ssl:
        min-version: TLSv1.2
        max-version: TLSv1.3
        certificate-file: /etc/letsencrypt/live/your-domain.com/fullchain.pem
        key-file: /etc/letsencrypt/live/your-domain.com/privkey.pem

    # UDP 监听器（HTTP/3 over QUIC）
    listen:
      <<: *listen_ssl
      type: quic
      quic:
        retry: ON
        max-streams-bidi: 64
        pacing: ON

    # 安全响应头
    header.set:
      - "Strict-Transport-Security: max-age=63072000; includeSubDomains; preload"
      - "X-Content-Type-Options: nosniff"
      - "X-Frame-Options: SAMEORIGIN"
      - "Referrer-Policy: strict-origin-when-cross-origin"
      - "Permissions-Policy: accelerometer=(), camera=(), geolocation=(), gyroscope=(), magnetometer=(), microphone=(), payment=(), usb=()"
      - "Content-Security-Policy: default-src 'self'; script-src 'self' 'unsafe-inline' https:; style-src 'self' 'unsafe-inline' https:; img-src 'self' data: https:; connect-src 'self' https: wss:"

    # 反向代理配置
    paths:
      # 静态资源路径（启用强缓存）
      "/js/":
        proxy.reverse.url: http://127.0.0.1:8080/js/
        header.set:
          - "Cache-Control: public, max-age=31536000, immutable"
        proxy.timeout.io: 300
        proxy.preserve-host: ON
        proxy.tunnel: ON

      "/css/":
        proxy.reverse.url: http://127.0.0.1:8080/css/
        header.set:
          - "Cache-Control: public, max-age=31536000, immutable"
        proxy.timeout.io: 300
        proxy.preserve-host: ON
        proxy.tunnel: ON

      "/img/":
        proxy.reverse.url: http://127.0.0.1:8080/img/
        header.set:
          - "Cache-Control: public, max-age=31536000, immutable"
        proxy.timeout.io: 300
        proxy.preserve-host: ON
        proxy.tunnel: ON

      # 默认路径
      "/":
        proxy.reverse.url: http://127.0.0.1:8080
        header.set:
          - "X-Forwarded-Proto: https"
        proxy.timeout.io: 300
        proxy.preserve-host: ON
        proxy.tunnel: ON
```

## OpenResty 配置

OpenResty 是基于 Nginx 的 Web 平台，集成了 LuaJIT，提供了强大的动态脚本能力。

### 安装 OpenResty

```bash
# Ubuntu/Debian
wget -qO - https://openresty.org/package/pubkey.gpg | apt-key add -
add-apt-repository -y "deb http://openresty.org/package/ubuntu $(lsb_release -sc) main"
apt update
apt install openresty -y

# CentOS/RHEL
yum install yum-utils
yum-config-manager --add-repo https://openresty.org/package/centos/openresty.repo
yum install openresty -y
```

### 基础配置示例

```nginx
# /usr/local/openresty/nginx/conf/rustblog.conf

upstream rustblog_backend {
    server 127.0.0.1:8080;
    keepalive 32;
}

# 初始化共享内存
init_by_lua_block {
    -- 初始化 Lua 模块
}

# HTTP 强制跳转 HTTPS
server {
    listen 80;
    server_name your-domain.com;
    return 301 https://$server_name$request_uri;
}

# HTTPS 主配置
server {
    listen 443 ssl http2;
    server_name your-domain.com;

    # SSL 证书配置
    ssl_certificate /etc/letsencrypt/live/your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;

    # SSL 优化配置
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers 'ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-RSA-AES256-GCM-SHA384';
    ssl_prefer_server_ciphers off;
    ssl_session_timeout 1d;
    ssl_session_cache shared:SSL:10m;

    # 安全响应头
    add_header Strict-Transport-Security "max-age=63072000; includeSubDomains; preload" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header Referrer-Policy "strict-origin-when-cross-origin" always;

    # Lua 访问控制
    access_by_lua_block {
        -- IP 黑名单检查
        local blacklist = {"192.168.1.100", "10.0.0.50"}
        local remote_ip = ngx.var.remote_addr

        for _, ip in ipairs(blacklist) do
            if remote_ip == ip then
                ngx.exit(403)
            end
        end
    }

    # 反向代理配置
    location / {
        proxy_pass http://rustblog_backend;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Connection "";
    }

    # 自定义 API 路由（使用 Lua）
    location /api/status {
        content_by_lua_block {
            ngx.header.content_type = "application/json"
            ngx.say('{"status":"ok","timestamp":"' .. ngx.now() .. '"}')
        }
    }
}
```

### 高级功能示例

```nginx
# 速率限制
lua_shared_dict rate_limit 10m;

init_by_lua_block {
    local rate_limit = require "resty.core.base".get_shdict("rate_limit")
    -- 初始化速率限制配置
}

server {
    location / {
        access_by_lua_block {
            local limit = 100  -- 每分钟 100 次请求
            local key = ngx.var.remote_addr
            local dict = ngx.shared.rate_limit

            local current = dict:get(key) or 0
            if current >= limit then
                ngx.exit(429)  -- Too Many Requests
            else
                dict:incr(key, 1, 60)  -- 60 秒过期
            end
        }

        proxy_pass http://rustblog_backend;
    }
}

# WAF 功能（简单示例）
location / {
    access_by_lua_block {
        local forbidden_paths = {"/admin", "/wp-login.php", "/.env"}
        local uri = ngx.var.request_uri

        for _, path in ipairs(forbidden_paths) do
            if string.find(uri, path) then
                ngx.log(ngx.WARN, "Blocked access to: " .. uri)
                ngx.exit(403)
            end
        end
    }

    proxy_pass http://rustblog_backend;
}
}
```

## 证书配置

## 性能对比

| 特性 | Nginx | H2O | OpenResty |
|------|-------|-----|-----------|
| HTTP/2 支持 | ✅ | ✅ 优秀 | ✅ |
| HTTP/3 支持 | ✅ (需额外模块) | ✅ 原生支持 | ❌ (需额外模块) |
| 性能 | 优秀 | 优秀 | 优秀 |
| 零拷贝 | 部分支持 | ✅ 完整支持 | 部分支持 |
| Lua 脚本 | ❌ | ❌ | ✅ 原生支持 |
| MRuby 脚本 | ❌ | ✅ 原生支持 | ❌ |
| 配置复杂度 | 中等 | 中等 | 较高 |
| 社区支持 | 非常活跃 | 活跃 | 活跃 |

**推荐选择**：
- **Nginx**：适合大多数场景，配置简单，社区资源丰富
- **H2O**：需要 HTTP/3 支持或极致性能时选择
- **OpenResty**：需要复杂业务逻辑、API 网关功能时选择

## 故障排查

### 常见问题

1. **502 Bad Gateway**
   - 检查后端服务是否正常运行
   - 检查代理配置中的端口是否正确
   - 检查keep-alive设置
   
2. **证书错误**
   - 确认证书路径正确
   - 检查证书是否过期

3. **连接超时**
   - 增加 `proxy_timeout` 配置
   - 检查防火墙规则

## 总结

使用反向代理网关部署 RustBlog 可以带来显著的性能提升和安全增强。根据您的具体需求选择合适的网关软件：

- **快速部署**：选择 Nginx
- **最佳性能**：选择 H2O
- **复杂业务逻辑**：选择 OpenResty

无论选择哪种网关，都建议配置 SSL/TLS、启用压缩、设置合理的缓存策略，以获得最佳的用户体验。
