# 性能概述

## 轻量级资源占用

RustBlog 经过深度编译优化，在2核2G服务器上表现出色：

### 内存占用

- **启动时内存**：约 17MB（峰值 17.2MB）
- **运行时内存**：约 25MB（长期运行稳定）
- **峰值内存**：约 156MB（4:00被脚本漏扫,可以通过网关设置拦截缓解）
- **任务数**：7-8 个（系统限制 1974）

### CPU 使用

- **启动 CPU**：约 796ms
- **长期运行 CPU**：13小时累计 25.758s（平均极低）

### 包体大小

- **编译后体积**：约 5.1MB（纯静态链接 + UPX 压缩）

## 优化特性

- **纯静态链接**：无需系统依赖，单文件部署
- **UPX 压缩**：极致压缩，最小化存储占用
- **深度编译优化**：LTO (Link-Time Optimization)、codegen-units=1
- **零成本抽象**：Rust 语言特性确保高性能

## 适用场景

专为轻量级服务器设计，非常适合：
- 小型 VPS（2核2G 或更低）
- 边缘计算设备
- 资源受限的容器环境
- 低带宽网络环境
