# 欢迎使用 RustBlog

欢迎来到 RustBlog，一个高性能、低资源占用的现代化博客系统。

## 为什么选择 RustBlog

### 🚀 极致性能

RustBlog 采用纯 Rust 后端实现，经过深度编译优化：

- **超低内存占用**：2核2G服务器启动内存 < 25MB，运行时内存 < 80MB
- **极致压缩**：UPX 优化后体积仅约 5.1MB，纯静态链接无需系统依赖
- **高性能架构**：基于 Actix-Web 和 Tokio 异步运行时，处理效率卓越
- **智能缓存**：支持多种缓存后端，自动选择最优方案

### 🌐 创新动态路由系统

RustBlog 的核心亮点是**动态路由引擎**：

- **运行时管理**：无需重启服务即可添加、修改、删除路由
- **热更新**：路由配置实时生效，零停机更新
- **多种策略**：Trie、Radix Tree、SIMD 优化等多种匹配策略
- **持久化存储**：支持文件、数据库、内存多种存储方式
- **快捷菜单**：集成快捷菜单，快速访问常用路由

这是一个专为现代 Web 应用设计的路由系统，让博客管理和扩展变得前所未有的灵活。

### 🎨 丰富功能

**内容管理**
- 完整的 Markdown 编辑器
- 智能文本摘要（TextRank 算法，无 AI 依赖）
- 文章归档和版本管理
- 附件上传和管理

**用户体验**
- 响应式设计，适配所有设备
- 自定义外观主题（颜色、字体、布局）
- 预置快捷键系统
- 音乐播放器小组件

**管理功能**
- 50+ 管理员设置项
- 评论系统（支持 Markdown）
- 用户权限管理
- 访问统计和分析

### 🔒 安全可靠

- **密码安全**：Argon2 加密存储
- **数据加密**：ECC 椭圆曲线加密
- **身份验证**：JWT token 认证
- **防护机制**：SQL 注入、XSS、CSRF 全方位防护
- **HTTPS 支持**：完整的 TLS 配置支持

### 📦 轻量部署

专为轻量级服务器设计，非常适合：

- 小型 VPS（1核2G 或更低）
- 边缘计算设备
- 资源受限的容器环境
- 低带宽网络环境

## 快速开始

1. **下载预编译版本**：访问 [GitHub Releases](https://github.com/swordreforge/simple-blog/releases)
2. **赋予执行权限**：`chmod +x rustblog`
3. **运行服务**：`./rustblog --enable-cache --cache-backend auto -r`

就这么简单！更多详细信息请参考：

## 技术栈

RustBlog 采用现代化技术栈，确保高性能和稳定性：

- **语言**：Rust 2024 edition
- **Web 框架**：Actix-Web 4.12
- **异步运行时**：Tokio 1.49
- **数据库**：SQLite（内置）
- **模板引擎**：Tera 1.20
- **前端**：原生 JavaScript + HTML5 + CSS3
