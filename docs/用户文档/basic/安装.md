# 安装指南

## 下载预编译版本

RustBlog 采用纯静态链接并经过 UPX 极致优化，无需依赖系统库，下载后即可直接运行。

### 获取发布版本

访问 [GitHub Releases](https://github.com/swordreforge/simple-blog/releases) 下载对应系统架构的二进制文件。

### 支持的架构

- **Linux x86_64** (amd64) - 推荐
- **Linux x86_64-musl** - 静态链接版本
- **Linux aarch64** (ARM64)
- **Windows x86_64**
- **其他架构** - 需自行编译

### 安装步骤

1. **下载二进制文件**

   根据您的系统架构选择对应的文件下载，例如：
   ```bash
   wget https://github.com/swordreforge/simple-blog/releases/latest/download/rustblog-linux-x86_64
   ```

2. **赋予执行权限**

   ```bash
   chmod +x rustblog-linux-x86_64
   ```

3. **移动到可写路径**（可选）

   ```bash
   sudo mv rustblog-linux-x86_64 /var/www/html/
   ```

4. **运行服务**

   ```bash
   ./rustblog-linux-x86_64 --enable-cache --cache-backend auto -r
   ```

## 自行编译

如果没有预编译的版本适合您的系统，可以自行编译。

### 环境要求

- **Rust 版本**：>= 1.85（支持 2024 edition）
- **操作系统**：Linux / macOS / Windows

### 重要提示：移除不稳定选项

如果您使用的是**稳定版本的 Rust**，需要先移除 `.cargo/config.toml` 中的 `-Z` 不稳定选项，否则编译会失败。

检查并编辑 `.cargo/config.toml`：
```bash
nano .cargo/config.toml
```

移除所有包含 `-Z` 的行，例如：
```toml
# [build]
# rustflags = ["-Z", "some-unstable-feature"]  # 移除此类行
```

### 编译步骤

1. **克隆仓库**

   ```bash
   git clone https://github.com/swordreforge/simple-blog.git
   cd rustblog
   ```

2. **构建 Release 版本**

   ```bash
   cargo build --release
   ```

3. **运行编译后的程序**

   ```bash
   ./target/release/rustblog --enable-cache --cache-backend auto -r
   ```

### 可选的编译特性

RustBlog 提供了多个可配置的功能模块，您可以根据需求选择启用：

| Feature | 说明 | 默认启用 | 适用场景 |
|---------|------|---------|---------|
| `default` | 默认配置（无额外功能） | ✅ | 基础使用 |
| `valkey` | 启用 Valkey/Redis 缓存支持 | ❌ | 高并发场景、多实例部署 |
| `profiling` | 启用性能分析工具（flamegraph） | ❌ | 性能调优、问题诊断 |
| `simd` | 启用 SIMD 优化的 JSON 解析 | ❌ | 高频 JSON 处理场景 |
| `jemalloc` | 使用 jemalloc 内存分配器 | ❌ | 高并发、多线程场景 |
| `mimalloc-alloc` | 使用 mimalloc 内存分配器 | ❌ | 通用内存优化 |
| `tcmalloc-alloc` | 使用 tcmalloc 内存分配器 | ❌ | 大规模内存分配场景 |
| `compressed-embed` | 启用嵌入资源压缩 | ❌ | 减小二进制文件体积 |

#### 功能模块详解

**`valkey` - 分布式缓存支持**
- 启用 Valkey/Redis 作为外部缓存后端
- 支持多实例部署时的缓存共享
- 提供比本地缓存更好的持久化能力
- 适合：负载均衡环境、高可用部署

**`profiling` - 性能分析工具**
- 集成 pprof 性能分析工具
- 生成 CPU/内存火焰图
- 帮助定位性能瓶颈
- 适合：开发调试、性能优化阶段

**`simd` - SIMD 加速**
- 使用 SIMD 指令集优化 JSON 解析
- 在支持 AVX2/SSE4.2 的 CPU 上性能提升显著
- 仅在频繁处理 JSON 数据时有用
- 适合：API 密集型应用

**`jemalloc` - jemalloc 分配器**
- Facebook 开发的高性能内存分配器
- 在高并发场景下内存碎片更少
- 适合：高并发 Web 服务

**`mimalloc-alloc` - mimalloc 分配器**
- Microsoft Research 开发的分配器
- 良好的扩展性和低内存开销
- 适合：通用服务器应用

**`tcmalloc-alloc` - tcmalloc 分配器**
- Google 开发的分配器
- 适合大规模内存分配场景
- 适合：内存密集型应用

**`compressed-embed` - 嵌入资源压缩**
- 使用 zstd 压缩嵌入的前端资源
- 减小最终二进制文件体积
- 会略微增加启动时间（解压开销）
- 适合：存储空间受限的环境

#### 编译示例

```bash
# 启用 Valkey/Redis 缓存支持
cargo build --release --features valkey

# 启用性能分析工具
cargo build --release --features profiling

# 启用 SIMD 优化
cargo build --release --features simd

# 使用 jemalloc 内存分配器
cargo build --release --features jemalloc

# 使用 mimalloc 内存分配器
cargo build --release --features mimalloc-alloc

# 使用 tcmalloc 内存分配器
cargo build --release --features tcmalloc-alloc

# 启用嵌入资源压缩
cargo build --release --features compressed-embed

# 组合多个特性（推荐的生产配置）
cargo build --release --features "valkey,jemalloc,simd"

# 完整功能集（性能优先）
cargo build --release --features "valkey,jemalloc,simd,compressed-embed"
```

## 运行参数

### 基础配置

```bash
# 启用缓存并使用自动后端（推荐）
./rustblog --enable-cache --cache-backend auto -r

# 指定端口（默认 8080）
./rustblog --port 8080

# 只读模式（禁止写入操作）
./rustblog -r
```

### 缓存配置

RustBlog 支持多种缓存后端，根据环境自动选择最合适的方案：

| 参数 | 说明 | 适用场景 |
|------|------|---------|
| `--enable-cache` | 启用缓存 | 所有环境推荐启用 |
| `--cache-backend auto` | 自动选择缓存后端 | 推荐，会智能选择最优方案 |
| `--cache-backend local` | 使用本地内存缓存 | 单实例部署 |
| `--cache-backend valkey` | 使用 Valkey/Redis | 多实例部署 |

**自动选择逻辑**：
- 优先使用 Valkey/Redis（如果可用）
- 降级到本地内存缓存
- 确保在任何环境下都能正常运行

### 目录配置

```bash
# 指定数据目录（默认 ./data）
./rustblog --data-dir /var/lib/rustblog

# 指定静态资源目录（默认 ./static）
./rustblog --static-dir /var/www/static

# 指定模板目录（默认 ./templates）
./rustblog --template-dir /var/www/templates
```

### 其他配置

```bash
# 查看所有可用参数
./rustblog --help

# 显示版本信息
./rustblog --version
```

### 推荐启动命令

**轻量级单实例**：
```bash
./rustblog --enable-cache --cache-backend auto -r
```

**生产环境**：
```bash
./rustblog --enable-cache --cache-backend auto -r --port 8080
```

## 系统服务配置（Linux）

使用 systemd 创建持久化服务：

1. **创建服务文件**

   ```bash
   sudo nano /etc/systemd/system/rustblog.service
   ```

2. **添加以下内容**

   ```ini
   [Unit]
   Description=RustBlog Service
   After=network.target

   [Service]
   Type=simple
   User=www-data
   WorkingDirectory=/var/www/rustblog
   ExecStart=/usr/local/bin/rustblog --enable-cache --cache-backend auto -r
   Restart=always
   RestartSec=10

   [Install]
   WantedBy=multi-user.target
   ```

3. **启用并启动服务**

   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable rustblog
   sudo systemctl start rustblog
   sudo systemctl status rustblog
   ```

## 验证安装

访问您的服务器地址，如果能正常显示博客首页，说明安装成功。

```bash
curl -I http://localhost:8080
```
