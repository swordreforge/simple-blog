# 功能特性

## 核心功能

### 文章管理
- 完整的 Markdown 文章编辑和发布系统
- 支持文章分类、标签管理
- 文章归档和历史记录
- 自动生成文章摘要
- 支持文章版本管理

### 可定制化主页
- **标题栏自定义**：自定义网站标题和导航菜单
- **底栏自定义**：自定义页脚信息和链接
- **欢迎语配置**：设置个性化欢迎信息
- 响应式设计，适配各种设备

> 详见：[外观设置](../advance/外观设置.md)、[模板设置](../advance/模板设置.md)

### 评论系统
- 支持 Markdown 格式评论
- 评论内容自动转换显示
- 无需登录即可评论
- 评论管理和审核功能

### 归档与统计
- 文章按时间归档展示
- 访问统计数据
- 文章阅读量统计
- 最新文章快速访问
- 网站整体数据概览

### 附件功能
- 图片附件上传和管理
- 支持多种文件格式
- 附件与文章关联
- 附件压缩和优化

## 高级功能

### 快捷键系统
- 预置符合直觉的快捷键绑定
- 全局快捷键支持
- 页面级快捷键
- 快捷键提示和帮助文档
- 可自定义快捷键配置

> 详见：[快捷键设置](../advance/快捷键.md)

### 音乐小组件
- 集成音乐播放功能
- 支持本地音乐文件
- 自动提取音频元数据（ID3、FLAC）
- 播放列表管理
- 音频封面显示

> 详见：[音乐设置](../advance/音乐设置.md)

### 动态路由系统
- 运行时动态添加/修改/删除路由
- 路由热更新，无需重启服务
- 多种路由匹配策略优化
- 路由存储持久化
- 快捷菜单集成

> 详见：[动态路由功能](../advance/动态路由功能.md)

### 智能文本摘要
- 基于 TextRank 算法的中文摘要
- 无 AI 依赖的纯算法实现
- 自动生成长文本摘要
- 语义相似度分析

## 管理功能

### 丰富的管理员设置
超过 50+ 项可配置的管理员设置，包括：
- 网站基本设置（标题、描述、关键词）
- 外观主题设置（颜色、字体、布局）
- 用户权限管理
- 评论审核设置
- 缓存配置
- 安全设置
- SEO 优化设置
- 备份与恢复
- 日志管理

> 详见：[外观设置](../advance/外观设置.md)、[模板设置](../advance/模板设置.md)、[常见问题](../advance/常见问题.md)

### 用户管理
- 用户注册和登录
- 权限控制
- 密码加密存储（Argon2）
- JWT 身份验证
- 会话管理

### 安全特性
- SQL 注入防护
- XSS 攻击防护
- CSRF 保护
- HTTPS 支持
- 安全响应头配置

## 性能优化

### 低资源占用
- 启动内存 < 25MB
- 运行内存 < 80MB
- 适合轻量级服务器部署

> 详见：[概述](概述.md)、[更高级的内存占用优化](../advance/更高级的内存占用优化.md)

### 高性能
- 纯 Rust 后端实现
- 异步 I/O 处理
- 智能缓存策略
- 静态资源压缩

### 编译优化
- LTO (Link-Time Optimization)
- UPX 压缩
- 纯静态链接
- 极致体积优化（约 5.1MB）
