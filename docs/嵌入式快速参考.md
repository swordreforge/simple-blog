# 嵌入式环境快速参考

## 🎯 一键构建

### 标准嵌入式版本（推荐）
```bash
./build-embedded.sh x86_64-unknown-linux-musl mimalloc-alloc
```

### ARM 64位版本
```bash
./build-embedded.sh aarch64-unknown-linux-musl mimalloc-alloc
```

### 极致优化版本（最小二进制）
```bash
./build-embedded.sh x86_64-unknown-linux-musl mimalloc-alloc true
```

## 🔧 环境变量配置

### mimalloc 优化
```bash
export MIMALLOC_SEGMENT_CACHE_ENABLED=1
export MIMALLOC_PAGE_RESET=1
export MIMALLOC_LARGE_OS_PAGES=1
```

### jemalloc 优化
```bash
export MALLOC_CONF="background_thread:true,dirty_decay_ms:1000,muzzy_decay_ms:1000,narenas:2"
```

## 📦 部署步骤

### 1. 构建
```bash
./build-embedded.sh x86_64-unknown-linux-musl mimalloc-alloc
```

### 2. 传输
```bash
scp -r embedded-release/* user@device:/opt/rustblog/
```

### 3. 启动
```bash
ssh user@device "cd /opt/rustblog && ./start.sh"
```

## 🔍 监控命令

### 内存使用
```bash
# 实时监控
watch -n 5 'cat /proc/$(pgrep rustblog)/status | grep -E "VmSize|VmRSS"'

# 详细信息
smem -P rustblog -c name pid vms rss
```

### 性能分析
```bash
# CPU 使用
top -p $(pgrep rustblog)

# 网络连接
netstat -anp | grep rustblog

# 磁盘 I/O
iotop -p $(pgrep rustblog)
```

## ⚙️ 性能调优

### 数据库优化（低内存设备）
```sql
-- 减少 SQLite 缓存
PRAGMA cache_size = -8000;     -- 8MB（默认 64MB）
PRAGMA mmap_size = 33554432;    -- 32MB（默认 256MB）
PRAGMA page_size = 4096;        -- 4KB 页面
```

### 连接池优化
```rust
// 修改 src/db/init.rs
const DB_MAX_CONNECTIONS: u32 = 3;   // 减少到 3
const DB_MIN_IDLE: u32 = 1;         // 最小空闲 1
```

### Worker 线程优化
```rust
// 减少 worker 数量
let workers = std::cmp::max(1, cpu_count / 2);  // 使用一半 CPU
```

## 🚨 常见问题

### Q: 内存不足怎么办？
```bash
# 1. 减少数据库缓存
# 2. 降低连接池大小
# 3. 使用系统默认分配器
# 4. 禁用非必要功能
```

### Q: 启动太慢怎么办？
```bash
# 1. 使用 jemalloc（更快但占用稍大）
# 2. 延迟初始化非关键组件
# 3. 减少启动时的数据库查询
```

### Q: 性能不足怎么办？
```bash
# 1. 增加 CPU 频率
# 2. 使用 jemalloc
# 3. 优化数据库查询
# 4. 增加缓存
```
